# Predicting Climate Change Attitudes: How Religious Beliefs and Political Attitudes Shape Regulation Support

In this project, five different classifiers - a decision tree, a logistic classifier, a random forest, XGBoost and SVM - are used to predict climate change attitudes. More precisely, we predicted support for climate change regulations based on religious beliefs, political attitudes, and socio-demographic variables. The analysis is based on the Religious Landscape Study 2023-24 dataset by the Pew Research Center, comprising a representative sample of U.S. adults.

> Importantly, this was a group project for a Data Mining university course. I contributed to the process as a whole, though my main contributions are the implementation and evaluation of the various classifiers (primarily the tree-based ones) as well as the theoretical framing and literature review. This file and the entire repository is a summary and shortened version of our collaborative work and project report.

## Replication

To replicate this project, clone the repository, set up a Python environment, download the raw dataset manually and then run all notebooks.

1. Clone the repository.

    ```bash
    git clone https://github.com/yamakoshimats/Predicting_Policy_Support.git
    cd Predicting_Policy_Support
    ```

2. Set up your virtual Python environment.

    ```bash
    python3 -m venv venv
    source venv/bin/activate        # Mac/Linux
    venv\Scripts\activate           # Windows
    pip install -r requirements.txt
    ```

3. Pipe the requirements for this project (see `requirements.txt`).

4. Download the dataset manually at [Pew Research Center](https://www.pewresearch.org/dataset/2023-24-religious-landscape-study-rls-dataset/). The raw data is not stored in this repo due to licensing and file size. You have to register a free Pew Research account. Then dowload the `.sav` dataset file and place it in `data/raw`.

5. Launch your IDE or jupyter.

6. Run the analysis notebooks in the following order:

    - Exploration of dataset `notebooks/01_exploration.ipynb`.
    - Preparing data for analysis `notebooks\02_preprocessing.ipynb`.
    - Data analysis `notebooks\03_modeling.ipynb`.
